# Sửa lỗi web: `ReferenceError: Cannot access 'Ce' before initialization`

## Root cause

File: `/var/www/tms-asgt/mobile/app/order-detail.tsx`

`dpStatusMap` (dòng 232, `useMemo`) bị dùng trong dependency array của `useEffect` ở **dòng 197** — nhưng nó được khai báo SAU đó. JavaScript `const` có temporal dead zone → crash khi component render.

```typescript
// DÒNG 183-197: useEffect references dpStatusMap
useEffect(() => {
    // ...
    if (selectedDpId && dpStatusMap[selectedDpId]?.completed) { ... }
}, [deliveryPoints, selectedDpId, dpStatusMap]); // ← CRASH: dpStatusMap chưa khởi tạo

// ... 35 lines later ...

// DÒNG 232: dpStatusMap mới được khai báo
const dpStatusMap = useMemo(() => { ... }, [deliveryPoints, checkpoints]);
```

Trong minified build, `dpStatusMap` → `Ce` → lỗi `Cannot access 'Ce' before initialization`.

## Fix

Di chuyển khai báo `dpStatusMap` lên trước `useEffect` ở dòng 183.

Cụ thể trong `order-detail.tsx`:

1. **Cắt** đoạn dòng 232-253 (`const dpStatusMap = useMemo(...)`)
2. **Dán** vào **trước** dòng 183 (`useEffect(() => { ...`)

Chỉ cần sắp xếp lại thứ tự khai báo trong component, không thay đổi logic.
