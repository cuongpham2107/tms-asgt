# Plan: Fix Critical KM Calculation Bugs

## 🚨 Critical Fixes (crash hoặc sai dữ liệu)

### 1. Fix `created_at` null crash trên DriverSwap

**Files:**
- `app/Http/Resources/TripResource.php:103`
- `app/Services/ShiftKmCalculatorService.php:107`

**Nguyên nhân:** `DriverSwap` model có `$timestamps = false` → `created_at` luôn null. Gọi `.lt()` trên null sẽ crash.

**Fix:** Dùng `id` thay `created_at` để so sánh thứ tự swap (swap nào tạo trước có id nhỏ hơn):

```php
// Trước:
if ($fromSwap->created_at->lt($toSwap->created_at)) {

// Sau:
if ($fromSwap->id < $toSwap->id) {
```

### 2. Thêm `orderBy` cho fallback handover KM query

**Files:**
- `app/Services/ShiftKmCalculatorService.php:93,102,248`
- `app/Http/Resources/TripResource.php:209,253,294` (trong `adjustedForSwapIn`, `adjustedForSwapOut`, `getHandoverKm`)

**Nguyên nhân:** `->value('km_reading')` hoặc `->first()?->km_reading` không có `orderBy` → trả về kết quả không xác định.

**Fix:** Thêm `->orderByDesc('occurred_at')` sau `->reorder()`:

```php
// Trước:
$this->checkpoints()->reorder()->where(...)->first()?->km_reading

// Sau:
$this->checkpoints()->reorder()->where(...)->orderByDesc('occurred_at')->first()?->km_reading
```

### 3. Fix `$tripHandoverKm` dùng checkpoint khác shift

**File:** `app/Services/ShiftKmCalculatorService.php:54-60`

**Nguyên nhân:** `$tripHandoverKm` lấy driver_swap **mới nhất** của trip (bất kể shift). Khi dùng làm fallback cho swap-IN/OUT, có thể lấy nhầm checkpoint của shift khác.

**Fix:** Bỏ `$tripHandoverKm` fallback cuối cùng, chỉ dùng per-shift query.
