# Fix: recalculateKm() — bảo vệ vehicle.current_mileage khỏi ghi đè sai

## Problem

`TripsTable::recalculateKm()` tại `TripsTable.php:453-454` luôn gán `vehicle.current_mileage = trip.end_km` mà không kiểm tra ngữ cảnh:

```
Trip A end_km=15,000 (sai) → vehicle=15,000
B chạy, nhập checkpoint → vehicle=20,000 ✓
Admin sửa Trip A end_km→13,000 → bấm Recalculate
→ vehicle.current_mileage bị ghi đè thành 13,000 ❌
→ Trip mới sau đó lấy start_km=13,000 → total_km sai
```

`vehicle.current_mileage` là nguồn cho `trip.start_km` của mọi chuyến mới (xem `StartedHandler.php:28`, `TripCheckpointService.php:223`), nên nếu nó bị hạ xuống sai thì mọi chuyến sau đều sai.

## Phân tích các phương án

### Phương án A: Forward-only (đơn giản nhất)

Chỉ cập nhật `vehicle.current_mileage` khi `end_km >= current_mileage`.

```php
if ($record->end_km > 0 && $record->vehicle) {
    if ((float) $record->end_km >= (float) $record->vehicle->current_mileage) {
        $record->vehicle->update(['current_mileage' => $record->end_km]);
    }
}
```

- ✅ Đơn giản, 1 dòng
- ✅ Chặn hoàn toàn việc ghi đè xuống giá trị thấp hơn
- ⚠️ Hạn chế: nếu trip A LÀ trip cuối cùng và km sai làm vehicle bị đội lên, admin sửa xuống → vehicle không được cập nhật (admin phải vào form Vehicle sửa tay)

### Phương án B: Smart — kiểm tra trip cuối cùng

Chỉ cập nhật vehicle nếu trip đang sửa là trip có `end_km` lớn nhất trên xe:

```php
if ($record->end_km > 0 && $record->vehicle) {
    $maxEndKm = Trip::where('vehicle_id', $record->vehicle_id)
        ->whereNotNull('end_km')
        ->max('end_km');

    if ((float) $record->end_km >= (float) $maxEndKm) {
        $record->vehicle->update(['current_mileage' => $record->end_km]);
    }
}
```

- ✅ Xử lý được cả trường hợp sửa trip cuối cùng
- ✅ Không ghi đè khi có trip mới hơn
- ⚠️ Vẫn có edge case: checkpoint km_reading của trip đang chạy (chưa có end_km) có thể > max(end_km)

### Phương án C: Toàn diện — kiểm tra cả checkpoint đang chạy

```php
if ($record->end_km > 0 && $record->vehicle) {
    $maxKm = TripCheckpoint::whereHas('trip', fn($q) => 
        $q->where('vehicle_id', $record->vehicle_id)
    )->max('km_reading');

    $maxEndKm = Trip::where('vehicle_id', $record->vehicle_id)
        ->whereNotNull('end_km')
        ->max('end_km');

    $vehicleMax = max((float)($maxKm ?? 0), (float)($maxEndKm ?? 0));

    if ((float) $record->end_km >= $vehicleMax) {
        $record->vehicle->update(['current_mileage' => $record->end_km]);
    }
}
```

- ✅ An toàn tuyệt đối
- ⚠️ Phức tạp hơn, thêm query

## Đề xuất

**Chọn Phương án B** — cân bằng giữa an toàn và đơn giản:
- Kiểm tra max(end_km) của tất cả trip trên cùng xe
- Chỉ cập nhật vehicle khi trip đang sửa có end_km >= max đó
- Đủ an toàn cho thực tế (checkpoint readings của trip đang chạy hiếm khi vượt quá end_km của trip đã hoàn thành)

Nếu cần thêm, có thể nâng lên Phương án C sau.
