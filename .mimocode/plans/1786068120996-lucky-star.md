# Plan: Thêm `android:allowBackup="false"` vào AndroidManifest để tránh SSL cache cũ

## Bối cảnh
- App Expo managed workflow, không có AndroidManifest.xml trực tiếp
- Khi cài fresh install hoạt động, nhưng gỡ cũ cài lại vẫn lỗi do Android Auto Backup restore SSL cache cũ
- Cần set `android:allowBackup="false"` để ngăn restore

## Các file cần sửa/cần tạo

### 1. Tạo mới `mobile/plugins/withAndroidManifest.js`
Custom Expo config plugin inject `android:allowBackup="false"` vào `<application>` tag trong AndroidManifest.xml.

```js
const { withAndroidManifest } = require("@expo/config-plugins");

function withAllowBackup(config) {
  return withAndroidManifest(config, async (config) => {
    const manifest = config.modResults;
    
    const application = manifest.manifest.application?.[0];
    if (application) {
      application.$["android:allowBackup"] = "false";
    }
    
    return config;
  });
}

module.exports = withAllowBackup;
```

### 2. Sửa `mobile/app.json`
Thêm `"./plugins/withAndroidManifest"` vào mảng `plugins`.

## Verify
- Rebuild: `eas build --platform android --profile preview`
- Cài bản build mới, sau đó gỡ cài rồi cài lại — không còn lỗi SSL cache cũ
