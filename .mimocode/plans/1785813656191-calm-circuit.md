## Root Cause (3 tầng)

### Tầng 1: DriverSwapAction không tạo TripCheckpoint

`DriverSwapAction` (`app/Filament/Resources/Trips/Actions/DriverSwapAction.php:108-127`) chỉ tạo `DriverSwap` record + cập nhật Trip/Order status, **không tạo TripCheckpoint loại `driver_swap`**.

So sánh các path tạo driver swap:

| Path | Code | Tạo TripCheckpoint? | Tạo DriverSwap record? |
|------|------|--------------------|----------------------|
| EndHandler (end-vehicle) | `EndHandler.php:52-56` | ✅ CheckpointFactory | ❌ |
| EndShiftAction | `EndShiftAction.php:86-93` | ✅ TripCheckpoint::create | ❌ |
| TripController::complete() | `TripController.php:290-299` | ✅ CheckpointFactory | ❌ |
| **DriverSwapAction** | `DriverSwapAction.php:108-127` | **❌ THIẾU** | ✅ |

### Tầng 2: CheckpointFactory dedup ngăn tạo checkpoint thứ 2

`CheckpointFactory::createForAllOrders()` (line 40-44) bỏ qua order đã có checkpoint cùng type. Với `Started`, `ArrivedPickup`, `LeftPickup` thì đúng, nhưng **`DriverSwap` có thể xảy ra nhiều lần** trên 1 trip.

Không sửa tầng này → dù có thêm factory call vào DriverSwapAction, swap thứ 2 vẫn không tạo ra checkpoint.

### Tầng 3: TripResource::adjustedKmForDriver() dùng sai handover cho multi-swap

Khi `handover_km` null (dòng 111-118 và 148-155), code fallback về `driver_swap` checkpoint **mới nhất** (`orderByDesc('occurred_at')->first()`). Với 2 swap nhưng chỉ 1 checkpoint, cả 2 `to_driver` đều nhận cùng 1 handover km → driver cuối bị tính dư, driver giữa bị 0.

### Hậu quả chuỗi trên mobile:

```
THIẾU checkpoint driver_swap → handover_km null → fallback sai → KM mobile sai
Driver giữa (107): shift 118 không có checkpoint nào → adjustedKmForDriver trả về 0
Driver cuối (124): dùng CP#837 (km=101200) làm handover → tổng 800km nhưng thực tế chỉ ~300km
```

## Fix

### Fix 1: DriverSwapAction — thêm tạo TripCheckpoint + validation + update vehicle

**File**: `app/Filament/Resources/Trips/Actions/DriverSwapAction.php`

Thêm vào action closure:
- Validate `handover_km > 0` server-side (hiện tại form có `required()` nhưng vẫn pass null/0)
- Cập nhật `vehicle.current_mileage = handover_km`
- Gọi `CheckpointFactory::create()` với `CheckpointType::DriverSwap` **trước** khi update trip (để checkpoint ghi nhận đúng driver/shift cũ)

```php
// Sau line 117 (sau DriverSwap::create), trước $record->update(...)
use App\Enums\CheckpointType;
use App\Services\Trip\CheckpointFactory;

// Validate server-side
if (empty($data['handover_km']) || (float) $data['handover_km'] <= 0) {
    Notification::make()->danger()->title('Vui lòng nhập km chuyển giao hợp lệ')->send();
    $this->halt();
    return;
}

// Update vehicle
$record->vehicle->update(['current_mileage' => $data['handover_km']]);

// Create driver_swap checkpoints for ALL orders in trip
app(CheckpointFactory::class)->create(
    $record,
    ['occurred_at' => now(), 'km_reading' => $data['handover_km']],
    CheckpointType::DriverSwap,
);
```

### Fix 2: CheckpointFactory — bỏ dedup cho DriverSwap

**File**: `app/Services/Trip/CheckpointFactory.php`

Sửa `createForAllOrders()` (line 37-47) để không dedup khi type là `DriverSwap`:

```php
private function createForAllOrders(Trip $trip, array $payload, CheckpointType $type): Collection
{
    return $trip->orders
        ->reject(function ($order) use ($trip, $type) {
            if ($type === CheckpointType::DriverSwap) {
                return false; // Cho phép nhiều driver_swap checkpoint
            }
            return TripCheckpoint::where('trip_id', $trip->id)
                ->where('order_id', $order->id)
                ->where('checkpoint_type', $type->value)
                ->exists();
        })
        ->map(fn ($order) => TripCheckpoint::create(
            $this->buildData($trip, $payload, $type, $order->id, $payload['delivery_point_id'] ?? null)
        ));
}
```
