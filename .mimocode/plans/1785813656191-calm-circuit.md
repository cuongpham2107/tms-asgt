# Fix TripResource fallback — dùng sai checkpoint khi có 2+ swap

## Bug

`TripResource::adjustedForSwapIn()` (line 111-117) và `adjustedForSwapOut()` (line 148-155) khi `handover_km = null` đều fallback bằng:

```php
->where('checkpoint_type', 'driver_swap')
->orderByDesc('occurred_at')
->first()
```

Với 2+ swap trên 1 trip, luôn lấy checkpoint **mới nhất toàn cục** → swap thứ nhất bị gán sai handover.

## Dữ liệu thực tế Trip 153

| Driver | Swap check | Fallback hiện tại | KM đúng | Mobile thấy |
|--------|-----------|-------------------|---------|-------------|
| 107 | Swap#55 OUT | CP#850 (100900) ✗ | CP#847 (100860) | total=50 ✗ (đúng 10) |
| 189 | Swap#55 IN | CP#850 (100900) ✗ | CP#847 (100860) | total=0 ✗ (đúng 40) |
| 104 | Swap#56 IN | CP#850 (100900) ✓ | CP#850 (100900) | total=60 ✓ (trùng may mắn) |

## Root cause

Checkpoint `driver_swap` có `shift_id = from_shift_id` của swap tương ứng:
- CP#847 shift=120 ↔ Swap#55 from_shift=120
- CP#850 shift=122 ↔ Swap#56 from_shift=122

Nhưng fallback không dùng `from_shift_id` mà dùng `orderByDesc` bất kể swap nào.

## Fix

Thay `orderByDesc('occurred_at')` bằng `where('shift_id', $swap->from_shift_id)` ở cả 2 method.

**File**: `app/Http/Resources/TripResource.php`

### adjustedForSwapIn (line 111-117):
```php
// Before:
->orderByDesc('occurred_at')
// After:
->where('shift_id', $swap->from_shift_id)
```

### adjustedForSwapOut (line 148-155):
```php
// Before:
->orderByDesc('occurred_at')
// After:
->where('shift_id', $swap->from_shift_id)
```

## Verification

Tinker kiểm tra Trip 153 sau fix → driver 107: 10/10, driver 189: 40/40, driver 104: 60/50.
