# Fix loadedKm = 0 cho swap-IN khi chưa complete đơn nào

## Bug

Driver swap-IN (nhận chuyến giữa chừng) bị `loaded_km = 0` dù đơn hàng đang trên xe.

### Trip 156: 3 drivers 107→109→113

```
start(109000) → pickup(109100) → left→arrived_delivery(109400) → 
   [swap#57 km=109500] → [swap#58 km=109800] → completed(109900) → end(110000)
```

| Driver | Segment | Có hàng trên xe? | total | loaded | expected |
|--------|---------|------------------|-------|--------|----------|
| 107 | 109000-109500 (swap-OUT) | từ 109100 | 500 | 400 ✅ | 400 |
| **109** | **109500-109800 (swap-IN)** | **từ 109100** | **300** | **0** ❌ | **300** |
| 113 | 109800-110000 (swap-IN) | đến 109900 | 200 | 100 ✅ | 100 |

### Root cause

`TripResource::adjustedForSwapIn()` (line 130-135) và `ShiftKmCalculatorService` (line 88-93, 155-159):

```php
// Chỉ tính loaded nếu shift có completed checkpoint
$loadedKm = $completedKm !== null ? $completedKm - $handoverKm : 0;
```

Driver 109 không có `completed` checkpoint trong shift 125 → loaded = 0.

Nhưng thực tế: order đã được pick up từ km=109100 < handover=109500, và chưa complete trong segment này → order trên xe suốt 300km → loaded = total = 300.

### Quy tắc đúng (theo user)

| Đoạn | Loại |
|------|------|
| Start → ArrivedPickup | Không hàng (empty) |
| ArrivedPickup → Completed | Có hàng (loaded) |
| Completed → End | Không hàng (empty) |

Với swap-IN: nếu có `arrived_pickup` trước handover mà chưa có `completed` trong shift → loaded = total.

## Fix

### File 1: `app/Http/Resources/TripResource.php` — `adjustedForSwapIn()`

Thay dòng 130-135:

```php
// Before:
$loadedKm = $completedKm !== null ? max(0, (float) $completedKm - $handoverKm) : 0;

// After:
if ($completedKm !== null) {
    $loadedKm = max(0, (float) $completedKm - $handoverKm);
} else {
    $wasLoadedBefore = $this->checkpoints()
        ->where('checkpoint_type', 'arrived_pickup')
        ->where('km_reading', '<=', $handoverKm)
        ->exists();
    $loadedKm = $wasLoadedBefore ? $totalKm : 0;
}
```

### File 2: `app/Services/ShiftKmCalculatorService.php` — attempt 1 & 3

Sửa 2 vị trí (line 93 và line 159) cùng logic.
